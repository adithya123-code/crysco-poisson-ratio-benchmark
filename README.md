\# CrysCo Benchmark



Independent benchmarking and reproduction work based on the CrysCo

crystal graph-transformer framework.



\## Purpose



This repository contains my independent experimental work, preprocessing

pipelines, benchmark configurations, training results, and evaluation

outputs.



The original CrysCo implementation is maintained separately and is not

modified as part of this work.
